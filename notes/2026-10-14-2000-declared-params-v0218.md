# Declared parameters, the commented CSV, the hold-view filter (engine 0.2.18, L24 to L26, roadmap W2)

## Goal

The three hold-page items the Lyons v2 runs exposed: every upstream project opened an organ
sign-off hold right after the confirm because no parameter could be set at init (L24); the
draft exclusion file drew as fifty blank rows because `present` read its `#` comment as the
header (L25); a hold view could not narrow a table to the proposed value (L26).

## Done

- `objective.yml` `params: {<step>: {<parameter>: <value>}}` (design 2.5; the owner chose this
  form over an `init --set` flag): `config.Objective.params`; `project._init_in` refuses an
  unknown step or parameter (exit 15), on `init` and `declare --check` alike; `echo.generic_echo`
  lists them under "Parameters declared"; `steps.starting_params` seeds a step's proposal with
  them (label `declared`) below the operator's `--set` and below a fork's inherited values; the
  run loop and `propose` use it; `fork.ancestor_params` keeps `declared` across forks;
  `proposed_by` can be `declared`; a project with declared parameters does not inherit its
  confirmation. `param.agent_proposed` untouched: a declared value is never asked; a `--set`
  that departs from it is the agent's and is.
- `present._data_lines` drops leading `#` lines for `_rows_from_table` and `_captions`.
- `hold_view` (and `after_delivery`) table entries take `where: {column, equals}`;
  `equals: $param.<name>` resolves to the hold's proposed value through `_marked_value`; a hold
  without that value shows every row with a `note`, printed by the Markdown and HTML renderers.
- Tests: `tests/test_declared_params.py` (echo, run with no hold, `fork --check` keeps
  `declared`, a departing proposal is the agent's; refusals at init and `declare --check`);
  `tests/test_board_present.py` (the commented CSV; `where` by parameter, by literal, and the
  note). Full suite, ruff, mypy, no-biology green; version 0.2.18, golden, lock.
- Design 2.5; DECISIONS (three entries); `spec/method-skills.md` section 2; the declare skill's
  objective shape; the operator skill's section 8; L24 to L26 to `backlog-done.md`; roadmap.

## Learned

- `review_serve._decision_rows` hardcodes `source: agent` for `proposed` evidence, which is
  right: that evidence comes only from `param.agent_proposed`. The plan's item to change it was
  unnecessary.

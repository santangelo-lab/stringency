## Learned

- Two silent-failure classes surfaced and were guarded: the hash-order/positional-join pair
  (splitter + qc-cells keyed join + predicate), and thresholds tuned on another panel (ROSC
  spleen values removed 15 to 35 percent of splenocytes; revised with the owner's rationale).
- XOA 6.1 cell boundaries exceed 25 vertices; the splitter's zarr output is skipped (backlog).
- Engine gaps (all recorded in the plan file): directory inputs/outputs and symlinked binds
  (fixed, uncommitted); `propose --new` (added, uncommitted); extractors run in the first step's
  env (worked around in the nextflow image); `repro.intermediate_dropped` ignores `$inputs`
  re-binds (policy override); one default per pipeline param; `abandon` leaves the step row
  `running`; a variable-arity input type is needed for the cross-region summary.
- Operator lessons: long operator-run steps need a detached launcher (`setsid nohup`) because a
  session tool call is capped at ten minutes; kill by pid, never `pkill -f` with a pattern the
  calling shell also matches; `run --until` executes the step with pipeline defaults, so a
  parameter proposal on step 1 must be `propose --new`.

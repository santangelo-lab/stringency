## Learned

- Every bare exemption that read a value was open to the same coincidence, not only the new
  `table` class: in a sweep the swept parameter's values are the row keys, the considered
  values and the proposed value at once. Closing it meant withdrawing L93's and L142's bare
  exemptions too.
- The cost of a convention is paid where a lapse lands. A bare name in an answer blocks and
  the operator mends it; in a proposal it would have opened a hold for a person. The refusal
  before the write moves that cost back to the operator.
- A `call` runs the tool's controls before it proposes, so "nothing was recorded" was not true
  of a refused call; the message says no proposal was recorded.

## Altered

- L142's and L93's bare exemptions are withdrawn (DECISIONS 2026-11-10). Running projects on
  the old skills will see answers block and proposals refused until the names are marked; the
  messages say what to do.
- No contract changed: the predicate versions are the unreleased `@3`; exit 16 is used as
  `deliver --story` uses it.

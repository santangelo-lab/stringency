## Learned

- The real Nextflow trace on this machine (`MTA_pipeline_segmentation/smalltest_current`) has no
  `container` column; verification from a trace needs `trace.fields` to include it. A second
  fixture with containers covers that path.
- `jsonschema` cannot resolve `#/$defs/...` inside a nested schema, so the `all_items` envelope
  hoists `$defs` to the top level.
- Under the default toy filter (`min_value: 10`) group C loses its low values and its spread drops
  below 20; the mock fixture keys C on spread over 15 and mean over 60, which also keeps the
  shuffled negative control abstaining.
- `uv run` re-syncs the environment and removes anything installed with `uv pip`; use
  `uv run --no-sync` after installing the singlecell skeleton for a manual check.
- No `gh` on BMESEQ and no HTTPS token; pushes work over SSH as `jrose835`. New org repositories
  have to be created in the GitHub UI.

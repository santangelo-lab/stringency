# A fork inherits its parent's parameters (engine 0.2.17, backlog L27, roadmap W1)

## Goal

The first engine item of `roadmap-2026-10.md`: the Lyons v2 spleen re-fork of 2026-10-12 ran at
the pipeline defaults for ndim and the clustering method after a person had signed both off,
because a fork rebuilt every re-run step from defaults plus its own `--set` delta (L27; the code
review's highest-ranked engine issue).

## Done

- `fork.ancestor_params` walks `runs.parent_run_id` to the nearest run that completed the step
  and reads its latest `actions` row; `inherited_for(rc, step)` is the run loop's and
  `propose`'s entry. `actions.build_action(inherited=)` merges proposed over inherited over
  defaults; labels `default` (the ancestor's default), `inherited`, `fork`, `agent`;
  `proposed_by` gains `fork` and `inherited`. A manual `propose` in a fork child starts from the
  inherited values and the fork's own delta (`cli/verb_propose.py`).
- `fork` prints every re-run step's parameters with their source and records the same table as
  `params` in the `fork` run event; `fork --check` prints it and opens nothing (`fork.check`,
  `resolved_params`, `render_params`; `--reason` is optional with `--check`). The console
  timeline renders a fork's delta as `step.param=value` (it printed the nested dict).
- Tests, `tests/test_controls_fork.py`: inheritance of an accepted non-default value with no new
  hold; through a parent that inherited (walk-up) and one generation on; `--check` opens no run
  and validates as `fork` does; `propose` by hand in a fork. The parent's proposal uses
  `01_filter.min_value=9`, chosen so the filtered table and the judgment are identical to the
  default (every toy value below 10 is below 8).
- Real data: `fork --check` on the Lyons v2 spleen run `01M4R92YK8KEB8WEWSZFQT1XM1` at
  `04_cluster` lists ndim 40 and `igraph_leiden` as inherited and the new resolution as `fork`.
- Design 2.6 and the 14.1 `fork` row amended (applied on the owner's "continue on"; the
  roadmap's "Needs the owner" says so); DECISIONS; L27 to `backlog-done.md`; the operator skill's
  section 8; version 0.2.17, golden, `uv lock`.

## Learned

- Parallel shell calls in this harness share one working directory: a `cd` in one call moved
  the others. Use absolute paths, or one sequential script.
- `coerce_value("none")` is `None`, so `--set correction=none` cannot name the toy's `none`
  option from the CLI; a pre-existing edge, not touched here.

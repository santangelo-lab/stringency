## Learned

- Every default project is class 4: `execution: operator` under a hosted operator makes the
  operator-run steps class 4, and the hosted operator session alone is class 3 because hold
  packets carry evidence lines. A ceiling below 3 needs `--operator-model none` or `local`, which
  is what the PROTECT projects will need to face.
- The scan over the Lyons method found one hit: `resegment-nextflow` `pre.sh:63 nextflow run`.
  The toy method has none.
- `reviews` is append-only; a reject in a test is written as its own row, not an update.
- `ControlProject` copies the base project's `__dict__`, so nothing on `Project` may cache the
  assessment.

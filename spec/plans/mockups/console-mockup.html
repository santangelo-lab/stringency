The operator's reason L8: the text behind rationale_ref

Recommend ndim thirty-five and resolution zero point four, the ROSC liver defaults, the values the owner approved on this organ's rc3 project ('Reasonable parameter choices'). The elbow table of the split-layer PCA that Harmony integrated is nearly identical to the uncorrected one: the knee heuristic lands at component sixteen, the cumulative-ninety-percent rule at thirty-two, the standard deviation stays above one point one through component forty, so the components between the knee and thirty-five still carry structure, which on a targeted panel is where rare populations separate. Thirty-five dimensions of the Harmony embedding keep the clustering comparable with the uncorrected run (twenty clusters at the same settings) and with ROSC; the development test of this route gave sixteen clusters. Resolution zero point four is kept for comparability; five resolutions are computed and clustree shows the alternatives.
